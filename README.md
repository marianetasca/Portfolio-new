# 💼 Portfólio - Mariane da Silva Tasca

Portfólio pessoal desenvolvido em React com suporte a dois idiomas (i18n), layout responsivo e foco em experiência do usuário.

## 🚀 Acesse o projeto
https://portfolio-iota-rust-34.vercel.app

## 🛠️ Tecnologias utilizadas
- React
- JavaScript
- HTML e CSS
- Tailwind CSS
- i18next

## ✨ Funcionalidades
- Layout responsivo
- Suporte a múltiplos idiomas (Português e Inglês)
- Alternância de idioma em tempo real
- Seção de projetos com links para demonstração e código
- Interface moderna com animações

## 🎯 Objetivo
Este projeto foi desenvolvido para apresentar meus projetos e consolidar conhecimentos em React, componentização e criação de interfaces modernas.
